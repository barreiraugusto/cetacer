5. Páginas del sitio

Dirección y Administración

Las páginas de contenido son listas de enlaces y documentos que se publican en la web, como «Legislación» o «Información útil». Cada una tiene su propia dirección, del tipo /info/legislacion/.

{% include "panel/ayuda/_captura.html" with archivo="paginas" ancho=1800 alto=780 pie="Las páginas de contenido cargadas." %}

Crear o modificar una página

  1. En Páginas, tocá + Nueva página o Editar.
  2. Cargá el título y, si querés, la bajada (el texto que aparece debajo del título).
  3. Dejá vacía la dirección web para que se arme sola a partir del título.
  4. En Enlaces, completá una fila por cada enlace: título, descripción y, o bien un enlace externo, o bien un archivo PDF subido. Nunca las dos cosas en la misma fila.
  5. Tocá Guardar página. El cambio se ve en la web de inmediato.
{% include "panel/ayuda/_captura.html" with archivo="pagina-editar" ancho=1800 alto=1725 pie="El formulario de una página, con sus enlaces debajo." %}
  • Grupo: los enlaces que tienen el mismo texto en «grupo» aparecen juntos bajo ese encabezado. Si lo dejás vacío, el enlace va suelto arriba de todo.
  • Orden: los números más chicos van primero.
  • Visible: desmarcalo para ocultar un enlace sin borrarlo.
  • Para borrar un enlace, marcá su casilla de eliminar y guardá la página.
  • Al pie siempre hay tres filas vacías para sumar enlaces. Si necesitás más, guardá y volvé a entrar.
  • Ver en la web → abre la página pública en otra pestaña.

Si un documento importa de verdad, subí el PDF en lugar de enlazarlo: los sitios ajenos dan de baja sus archivos sin avisar.

Si a un enlace le falta el destino, o tiene enlace externo y archivo a la vez, la página no se guarda: arriba aparece «Revisá los enlaces marcados en rojo, más abajo» y el enlace con el problema queda recuadrado en rojo, con la explicación.

{% include "panel/ayuda/_captura.html" with archivo="enlace-error" ancho=1107 alto=687 pie="Un enlace sin destino, marcado en rojo al intentar guardar." %}

Las tarjetas del inicio de la web enlazan puntualmente a las páginas con dirección «legislacion» e «informacion-util». Si les cambiás esa dirección, o las despublicás, la tarjeta deja de mostrar el enlace.

Despublicar o eliminar

Para sacar una página de la web sin perderla, desmarcá visible en la web: queda como «Borrador». Eliminar esta página, al pie del formulario, la borra junto con todos sus enlaces y no se puede deshacer.
